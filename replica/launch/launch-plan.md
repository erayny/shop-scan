# Launch plan (in-house rollout)

Liftside is the shop's own tool, so there is no landing page, pricing or store
listing (`landing.md`, `pricing.md`, `listing.json` skipped on purpose). The
"launch" is getting it into daily use safely.

## Week 0 — set up
- [ ] Buy one BLE OBD-II adapter (see README) and check its current price before ordering.
- [ ] Install on the Samsung tablet from the published link; fill in Settings.
- [ ] Run the manual checklist in `replica/test-plan.md` on 3 shop cars.

## Weeks 1–2 — run alongside the pro tablet
- [ ] On every car that comes in with a check engine light, scan with both tools.
- [ ] Note any code Liftside missed or explained badly; send them for the description list.
- [ ] Note adapter drop-outs and slow cars.

## Week 3 — decide
- If codes match on the engine side: Liftside becomes the quick-read and customer-report tool; the pro tablet stays for OEM work.
- Turn notes into the next build list (parity.md "Top five").

## Measures
- Scans per week; share of reports printed or texted; codes that Liftside described only by family (add these).
